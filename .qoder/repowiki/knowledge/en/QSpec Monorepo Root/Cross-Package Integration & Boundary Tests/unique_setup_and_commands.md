Integration suites detect Docker availability via `getContainerRuntimeClient()` and skip themselves with a descriptive warning when the runtime is missing; the CLI binary test requires a pre-built `packages/cli/dist/bin.js` and skips if it does not exist (the build must be run before `npm test`); all container-backed tests pin `postgres:16-alpine` and set `vi.setConfig({ testTimeout: 120_000, hookTimeout: 300_000 })` to accommodate container startup.
