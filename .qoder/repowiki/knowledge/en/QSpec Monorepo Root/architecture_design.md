The root is a private npm workspaces project (`packages/*`) that centralizes cross-cutting concerns for all child modules: `tsconfig.base.json` enforces a strict, composite TS compiler profile (ES2022 target, NodeNext module resolution, strict + isolatedModules) inherited by every package; `vitest.config.ts` discovers tests under `packages/*/src/**/*.test.*` and `test/**` with automatic JSX runtime so React-based renderers in the test suite compile uniformly; `package.json` scripts orchestrate the lifecycle — `prebuild` runs `scripts/copy-schemas.mjs` to seed JSON schemas consumed by docs/examples and CLI validation, `tsc --build` compiles all packages in dependency order, and `release:*` scripts invoke the publishing pipeline from `scripts_and_ci`. The three child scopes (docs_and_examples, scripts_and_ci, tests) are thus bound together through this shared workspace graph, schema artifact, and type-checked boundary contracts rather than direct imports.
